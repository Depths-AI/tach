Measurement contract

A GPU baseline, not a language baseline.

Both paths use generated Tach kernels, persistent GPU buffers, one compute pass, warm pipelines, and one queue wait per sample.

The unfused path is two physical dispatches with an explicit intermediate buffer. The fused path is one dispatch with that transient forwarded in registers.

Samples alternate fused-first and unfused-first. Upload, compilation, readback, CPU comparison, and report serialization are outside GPU timing.
